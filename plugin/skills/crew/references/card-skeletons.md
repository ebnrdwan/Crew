# Crew GitHub Project Card Skeletons

Templates for the draft cards `/crew push` creates on GitHub Projects v2 boards.

Cards are **live**: Crew creates one per feature at scoping time, then updates the Status field as the feature advances through phases. The card body uses these skeletons; the Status field is set programmatically via the logical state mapping in `.crew/config.yaml`.

---

## Card Types

Crew has 5 card types. Each maps a roadmap entry kind to a skeleton with the right required fields.

| Type ID | When to use |
|---|---|
| `feature` | New functionality being built from scratch |
| `enhancement` | Improvement or refinement of existing functionality |
| `bug` | Defect to fix; smaller scope, no new design |
| `infra` | DevOps / build / tooling change with no user-facing surface |
| `spike` | Time-boxed investigation when scope is unclear |

Each skeleton has three field categories:
- `📌 Required` — must be present at card creation
- `📝 Live` — Crew updates these automatically as phases progress
- `✏️ Manual` — left for the team to fill in

## Common Footer (every card)

```markdown
---

## 🛠 Crew Phase Status

**Current phase:** {phase_label}
**Logical status:** {logical_status}
**Last updated:** {YYYY-MM-DD HH:MM}

| Phase | Status |
|---|---|
| 1. Strategy | {phase_1_check} |
| 2. Design | {phase_2_check} |
| 2.5. Contract | {phase_25_check} |
| 3. Build | {phase_3_check} |
| 4. Quality | {phase_4_check} |
| 5. Launch | {phase_5_check} |

---

## 🗂 Crew Session Details

**Feature ID:** `{feature_id}`
**Source:** {source_origin}
**Roadmap entry:** [`.crew/roadmap.yaml`]({roadmap_url})
**Pages / endpoints:** {pages_or_endpoints}

{gang_link_line}

🤖 Generated by [Crew](https://github.com/ebnrdwan/Crew) · phase-based development workflow for Claude Code
```

`{phase_N_check}` is one of:
- `⏳ Pending` (not yet started)
- `🟡 In progress`
- `✅ Done`
- `⏭ Skipped` (e.g., Phase 2.25 hi-fi optional)

`{gang_link_line}` is only included when `source_origin == "gang"` — links to the source Gang evaluation:

```markdown
**Gang origin:** [`{slug}`]({gang_url}) · verdict {verdict_badge} · imported via gang-bridge
```

## Title format on phase update

When `/crew push` updates an existing card after a phase transition, only the **Phase Status** section + footer timestamp + Status field change. The title stays stable so links don't break.

If you want the phase to appear in the title for at-a-glance scanning on the board, use the title format above which embeds `{phase_label}` (e.g., `[Crew][Feature] login: PHASE 3 BUILD`). Crew rewrites the title via the GraphQL `updateProjectV2DraftIssue` mutation when phase changes — but only if `config.github.update_title_on_phase_change: true` in `.crew/config.yaml` (default: `false` to keep links stable).
