v0.1.0 Features

🧭
Phase-Based Workflow
6 phases from strategy to launch. Each phase has dedicated agents, gates, and outputs. Phase tracker in .crew/current-phase.yaml.
🚀
/crew drive
End-to-end product-led feature development: pm-architect → implementation → QA → gap audit. One command, full pipeline.
🔍
/crew gaps
5-phase UI gap audit: inventory → interact → inspect → compare → report. Auto-dispatches fix agents with verification.
📦
/crew deploy
Pre-deployment checklist with auto-remediation. Verifies env, runs health checks, dispatches agents to fix failures.
🌉
Gang Bridge
/crew gang-import brings GO Packages from Gang into the Crew roadmap. /crew gang-escalate sends stalled features back for re-scoring.
🎯
API Contract is Sacred
Zero-tolerance enforcement: docs/api-contract.md is single source of truth. Both ui-engineer and api-engineer must verify alignment before implementation.
🪜
Onboarding Wizard
/crew onboard detects project type (fullstack / frontend / backend / mobile), imports context, audits, and sets the right phase.
🌿
Git Workflow
Feature → task → subtask branching. Merge only on explicit user approval. /crew feature creates branches and tracks progress.
🔌
MCP Setup
/crew setup-mcp configures Jira, Notion, Linear, GitHub, SuperDesign and other MCP servers in one go.
📋
Feature Dashboard
/crew features shows roadmap status, pages, navigation flow, acceptance progress. Filterable by status/epic/priority.
🤖
20 Specialised Agents
No general-purpose agent fallback. Every phase has scoped specialists with clear boundaries — strategy, design, build, quality, launch.
🎨
Multi-Platform UI
One ui-engineer agent handles React, React Native, SwiftUI, and Jetpack Compose. Cross-platform consistency from styled-dsl.yaml.

Commands

/crew feature [name]Add a feature to the roadmap and start dev workflow
/crew drive [feature]End-to-end product-led feature development
/crew gaps [url]UI gap audit + auto-fix pipeline
/crew deploy [--phase --fix]Pre-deployment checklist with auto-remediation
/crew features [--status]Roadmap dashboard, filterable
